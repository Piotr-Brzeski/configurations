# Assistant Behavior

## Code Modification Policy
**Do NOT modify code unless the current message explicitly requests it.**
A previous request to edit code does not grant permission to edit in follow-up messages.

- If this message asks to "fix", "change", "refactor", "implement", "update", "add",
  "rewrite", "modify", "edit", or "delete" → you MAY edit code
- For ALL other messages → respond with text ONLY, no code edits
- When in doubt, ASK: "Do you want me to explain this or make a change?"

## Code Comments Policy
**Use only ASCII characters in generated code comments.** No Unicode, emoji, arrows (→), dashes (—), or other non-ASCII symbols.
